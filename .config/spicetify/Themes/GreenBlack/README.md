# GreenBlack

Mi tema anterior: fondo `#101010`, acento verde menta `#00e69a` y texto `#a8d5bf`. Los textos secundarios van en `#6b9e87`.

Para usarlo: `spicetify config current_theme GreenBlack && spicetify apply`.

Con Spicetify 2.46.2 hay que dejar `expose_apis = 1` y `experimental_features = 1` para que cargue. El tema nada más cambia CSS y colores.
