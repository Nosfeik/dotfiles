# GreenBlack

Fondo #101010, acento verde menta #00e69a y texto #a8d5bf, iguales a Kitty.
Los textos secundarios usan #6b9e87 y las selecciones un verde oscuro.

Para reaplicar: `spicetify apply`.
Para volver al tema anterior: `spicetify config current_theme XeruxBlack && spicetify apply`.

Con Spicetify 2.46.2, conserva `expose_apis = 1` y `experimental_features = 1`
para que se inserte correctamente el cargador de módulos. El tema solo añade CSS y colores.
