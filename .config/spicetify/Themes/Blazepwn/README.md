# Blazepwn

Fondo `#16181d`, acento `#60a5fa` y texto `#dce2ec`, igual que Kitty. Los textos secundarios van en `#8792a8`.

Para aplicarlo: `spicetify apply`. Para regresar a los grises: `spicetify config current_theme XeruxBlack && spicetify apply`.

Con Spicetify 2.46.2 hay que dejar `expose_apis = 1` y `experimental_features = 1` para que cargue. El tema nada más cambia CSS y colores.
